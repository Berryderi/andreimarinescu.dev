Work/05

Research Agent

A local research chat. Type research, ask a question, and the model fetches news, Wikipedia, SEC filings or links you paste, then answers with a citation on every claim. A checker flags any number, name or quote that isn't in those sources.

01Problem

Models make up numbers and quotes. I wanted answers I could trace to a source I could open.

02What I built

  • The chat page, served only on my PC.
  • The source fetchers.
  • The claim checker.
  • Nightly runs on fixed topics.

03How it was tested

Unit tests (99 passing after the last merge) and before/after evals when the answer style changed.

04Results

  • In one eval run the model invented a detail and hardened an allegation. I fixed the prompt and the next run was clean.
  • GDELT news requests hit that service's per-IP rate limit about 85% of the time; I added paced retries, which raised answered queries from 5 of 14 to 8 of 14.

05What I learned

A checker that reads the sources catches what the model won't admit. Free data sources have limits you have to design around.
