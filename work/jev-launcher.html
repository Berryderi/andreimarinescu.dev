Jev Launcher

Press Ctrl+Alt+Space, type or say what you want open in plain words, and it opens. "chrome on my school account, rocket league, and claude" opens all three. A local model plans the steps; anything destructive waits for a spoken yes.

01Problem

Opening the same apps every session takes clicks and remembering where each one lives. I wanted to say it once.

02What I built

  • A launcher that finds the apps on the device by itself, on Windows and Ubuntu.
  • Voice control and a hands-free pointer mode.
  • "Open anything": files and folders by name, and it asks when a name is ambiguous.
  • A PC agent on a local model that can see the screen and use apps. Anything destructive waits for a spoken yes.

03How it was tested

  • Speech model chosen by measurement on 46 of my own recordings.
  • An agent eval with tuned, held-out and blind cases, then runs in real apps.
  • 2,684 automated tests on the agent branch.

05What I learned

Measure on your own data before choosing a model: the speech model was picked from 46 of my own recordings.

Guards belong in code, not in the prompt: the agent once planned to delete a file with no confirm. The fix, enforced in code, is in review.
