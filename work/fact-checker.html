01Problem

Checking facts after writing is slow; I wanted it while typing.

02What I built

A Chrome extension that underlines false sentences in a Google Doc as you type, with a fix and a Wikipedia source, using a model on my own PC.

03How it was tested

  • A synthetic easy set of 20 sentences.
  • A mock document page.
  • A probe against a real private Google Doc.

04Results

  • 20/20 on the easy set, 0 wrong flags, median 1.8 s per check.
  • Underline on the mock page 2.9 s after the last key.

Honest limits

  • The set is synthetic and easy, so this is not an accuracy estimate.
  • In a real Google Doc, typed text was readable but pasted or existing text was not, and Chrome blocks the page from talking to a local server, so the underline was relayed, not live.

05What I learned

The hard part is the browser, not the model.
